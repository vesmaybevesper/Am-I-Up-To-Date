<p align="center">Am I Up To Date is a mod designed to be included in modpacks to check the local version against the most recent version and notify the user of an update. Offers a customizable widget for <a href="https://modrinth.com/mod/fancymenu">FancyMenu</a> & supports opening changelogs with <a href="https://modrinth.com/mod/rinku">Rinku</a>!</p>

## Compatibility

Mods that add elements to the main menu may shift or overlap the position of AIUTD's menu notice, and AIUTD's menu notice may shift or overlap main menu elements of other mods. These situations can be handled on a per-mod basis if requested.

**Currently "supported" mods:**
- [Vanilla Notebook](https://modrinth.com/mod/notebook)

## FAQ

**What modpack providers does this support?**
- Just Modrinth.


<details>
<summary>See Why</summary>

This mod only supports Modrinth modpacks for a few reasons.

1: The Modrinth app is the primary sufferer (or at least it was the last time I used it) of the issue this is addressing (that being no obvious visual cue that there is a new version). While some third-party launchers also suffer from this issue, the CurseForge app does an excellent job of showing when there are updates.

2: CurseForge is very strict about using their API; you have to [apply to get access](https://support.curseforge.com/support/solutions/articles/9000208346-about-the-curseforge-api-and-how-to-apply-for-a-key), and then if you get it and your connection is being used too much, [they may charge you](https://support.curseforge.com/support/solutions/articles/9000207405-curse-forge-3rd-party-api-terms-and-conditions#Use-of-Platform-API%C2%A0). Additionally, their terms state that only people who are [18 and older](https://support.curseforge.com/support/solutions/articles/9000207405-curse-forge-3rd-party-api-terms-and-conditions#Representations-and-Warranties-of-Developer) can even get an API key, which would limit which pack devs can use it. It is simply not worth the hassle of me getting a key to develop it or any pack devs getting a key to use it.

</details>
